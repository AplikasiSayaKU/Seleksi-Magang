Sinkronisasi Google Sheets / Cloud

Hubungkan website dengan Google Apps Script (Web App URL) agar data yang diinput otomatis tersimpan secara real-time ke Google Spreadsheet online Anda secara permanen.

Jika dikosongkan, data akan menggunakan penyimpanan browser (LocalStorage) + fitur Backup/Restore JSON.

Petunjuk Singkat Google Sheets:
  1. Buka Google Sheet > Ekstensi > Apps Script.
  2. Tempelkan skrip penerima data POST/GET JSON.
  3. Deploy sebagai Web App (Akses: Anyone/Siapa Saja).
  4. Salin URL Web App dan tempelkan di kolom atas.
